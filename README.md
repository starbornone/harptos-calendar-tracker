# harptos-calendar-tracker

Harptos Calendar Tracker is a planned Dungeon Master tool for tracking campaign time, daylight, and hourly weather in Neverwinter and Phandalin. The campaign starts on **1 Tarsakh 1491 DR, Year of the Scarlet Witch**.
