# harptos-calendar-tracker

Harptos Calendar Tracker is a Dungeon Master tool for campaigns that travel across Faerûn and other D&D settings. The Vite and TypeScript app uses shadcn/ui. Set or advance the Harptos clock, switch locations, and see local light, clock markers, and hourly weather. Use the copy icon beside the one-line campaign summary to copy it into your notes. Use **Share Campaign** to send a link to the current moment. Recipients can preview it and choose whether to adopt it as their saved campaign. Your browser saves the time, location, and weather seed. A new campaign starts in Neverwinter at **08:00 on 1 Tarsakh 1491 DR, Year of the Scarlet Witch**.
