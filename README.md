# harptos-calendar-tracker

Harptos Calendar Tracker is a Dungeon Master tool for a campaign in Neverwinter and Phandalin. The Vite and TypeScript app uses shadcn/ui. Set or advance the Harptos clock, switch locations, and see seasonal daylight, Faerûnian time markers, and hourly weather. Select the one-line campaign summary to copy it into your notes. Your browser saves the time, location, and weather seed. A new campaign starts in Neverwinter at **08:00 on 1 Tarsakh 1491 DR, Year of the Scarlet Witch**.
