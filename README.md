# harptos-calendar-tracker

Harptos Calendar Tracker is a Dungeon Master tool for Faerûn campaigns. The Vite and TypeScript app uses shadcn/ui. Set or advance the Harptos clock, switch among Neverwinter, Phandalin, Baldur’s Gate, and Waterdeep, and see local light, clock markers, and hourly weather. Use the copy icon beside the one-line campaign summary to copy it into your notes. Use **Share Campaign** to send a link to the current moment. Recipients can preview it and choose whether to adopt it as their saved campaign. Your browser saves the time, location, and weather seed. A new campaign starts in Neverwinter at **08:00 on 1 Tarsakh 1491 DR, Year of the Scarlet Witch**.

The tracker defaults to English. Browsers with a saved Simplified Chinese preference still use it for the interface, campaign summary, and footer disclaimer.

Open the [Harptos Calendar Tracker](https://harptos.starmist.studio/) or follow the local setup below.
